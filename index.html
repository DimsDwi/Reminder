Database Antar Perangkat

Hubungkan Firebase Firestore agar jadwal tersimpan di cloud dan otomatis muncul di komputer/HP mana saja.

Cara dapatkan konfigurasi gratis (2 menit):
  1. Buka Firebase Console (login akun Google).
  2. Buat proyek baru, lalu pilih Firestore Database -> klik Create database -> pilih Start in test mode.
  3. Pilih ikon Web (</>) untuk daftarkan aplikasi, lalu salin kode firebaseConfig ke bawah ini (atau simpan di berkas firebase-config.js).
